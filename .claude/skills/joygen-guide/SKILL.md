# JoyGen 平台指南

当用户询问关于 JoyGen 的问题时，参考 [references/joygen.md](references/joygen.md) 中的详细介绍来回答。

## 参考文档内容

该文档包含：

- **JoyGen 是什么**：AI 驱动的应用开发在线平台
- **核心功能**：
  - 生成网页和应用（活动页、管理后台、小工具等）
  - 生成文档（Word、Excel、PPT、PDF）
  - 生成业务流程（OA 审批流程）
  - 处理设计稿（识别 UI 设计图，转成代码）
- **与其他工具的区别**：
  - 完整的在线 IDE
  - 实时预览，所见即所得
  - 不只是写代码
  - 企业级可用
  - 普通人也能用
- **使用场景**：运营做活动页、产品经理验证想法、写周报、设计稿转代码、配置审批流程、编程学习等
- **技术特性**：
  - Skills 技能市场 (https://skillsmp.jd.com/)
  - MCP (Model Context Protocol) 工具扩展
  - 双引擎支持（Claude + Qwen）
  - 安全沙盒
- **官网**：https://joygen.jd.com
