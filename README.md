# 卫浴主图AI优化平台

## 项目简介

这是一个专为京东国内KA卫浴采销设计的 **AI Prompt 生成工具**，帮助采销人员快速生成专业的商品主图优化和虚拟组套提示词。

**核心定位：京点点 Oxygen Vision 的上游辅助工具**

> 💡 我们帮助采销人员快速生成专业 Prompt，让他们在使用京点点时事半功倍，真正发挥 AI 工具的最大价值。

## 核心功能

### 1. 主图优化
- **纯净背景**：去除杂乱背景，使用纯白或浅灰背景突出商品
- **场景合成**：将商品融入现代卫浴空间，营造使用场景
- **色彩增强**：优化色彩对比度，提升视觉吸引力
- **细节突出**：强化产品细节展示，如龙头电镀质感、陶瓷光泽
- **生活场景**：展示商品在真实使用环境中的效果

### 2. 虚拟组套
- **卫浴套装组合**：展示完整卫浴解决方案，体现产品配套性
- **促销组合**：突出促销氛围，可添加优惠标签或活动元素
- **季节组合**：结合季节元素（如温暖色调、季节氛围）
- **主题套装**：围绕特定主题设计组合，如智能卫浴、环保卫浴等

## 使用流程

### 完整工作流程

```
[JoyGen平台] → [生成工具] → [采销人员使用] → [京点点AI] → [专业设计图]
  (快速构建)    (生成Prompt)   (零培训上手)     (AI生成图片)
```

### 第一步：使用我们的工具生成 Prompt

1. **访问工具**：通过 JoyGen 平台部署的在线地址访问
2. **选择模式**：点击"主图优化"或"虚拟组套"
3. **填写信息**：
   - 主图优化：商品类型、品牌、优化场景、设计风格等
   - 虚拟组套：组套场景、产品数量、产品信息、设计风格等
4. **生成 Prompt**：点击"生成 Prompt"按钮
5. **复制 Prompt**：点击"复制"按钮

### 第二步：使用京点点 Oxygen Vision 生成图片

1. 打开京点点平台：https://oxygen-vision.jd.com/oxygenVision/home
2. 选择"自由创作"功能
3. 上传商品图片
4. 粘贴我们生成的 Prompt
5. 点击生成，获得专业设计图

### 第三步：应用到业务

1. 下载生成的专业设计图
2. 应用到商品主图、详情页、推广素材等
3. 享受高质量图片带来的转化率提升
